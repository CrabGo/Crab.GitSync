# Crab.GitSync v0.5.0

## 新增

- 网络设置增加分步连接诊断，分别显示代理端口、GitHub HTTPS、指定 Git 远端的状态和耗时，支持取消与错误详情。
- 任务日志增加逐仓库结果，显示失败阶段、尝试次数、耗时和脱敏错误详情；支持仅重试失败仓库并查看来源任务结果。
- 增加默认关闭的 fetch 网络自动重试开关；开启后对暂时性网络故障最多追加两次尝试，等待时可取消。
- 仓库列表显示已同步、本地领先、远端领先、双方分叉、无跟踪分支和未知提交关系，以及当前会话最后完整成功获取时间。
- 合并确认窗口显示源、目标引用与提交 ID，以及当前分支领先/落后提交数。

## 修改

- 合并和拉取并合并默认采用仅快进策略，双方分叉时停止；普通合并需主动选择策略并额外确认。
- 执行合并前及获取远端后重新校验分支、HEAD、工作区和目标；普通合并目标变化时需重新预览确认。
- fetch 成功但本地状态刷新失败单独标记，重试时只读取本地状态，不重复获取远端。

## 删除

- 无。

## 优化

- 统一代理、DNS、超时、认证、TLS、仓库状态和未知错误提示，保留脱敏原始详情；认证、证书及未知错误不自动重试。
- 提交关系、工作区修改、合并状态与任务结果分开展示，扫描不再暗示远端数据已刷新。
- 成功、跳过及取消项不混入失败重试；失败或部分远端成功不推进完整获取时间。
- 修正错误详情中 URL 外层引号被误编码的问题，保留日志地址可读性。
- 加强连续更新检查、代理协议、取消及真实临时仓库任务链的回归验证。
