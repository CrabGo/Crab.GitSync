# Crab.GitSync v0.5.1

## 新增

- 增加命名扫描列表，支持多个根目录以及相对、绝对路径排除规则。
- 工作台增加并发仓库数设置，默认 3 个，可调整为 1–5 个。
- 任务日志页增加持久化历史，可查看任务摘要、逐仓库结果及脱敏日志，并主动导出所选任务日志。
- 增加历史保留设置，默认最多 100 个任务或 30 天；重启后恢复历史记录和仓库最后完整成功获取时间。
- 应用更新页显示待更新版本的正式更新日志，发布附件增加同版本 CHANGELOG.md。

## 修改

- Git 任务、状态读取及更新重启使用统一调度与互斥；共享 Git 目录的工作树也受同一仓库锁保护。
- 批量获取显示等待、获取、刷新和终态，单个仓库失败后其他仓库继续执行。
- 历史失败获取支持重试，执行前仍重新校验当前扫描范围；过期历史不再通过会话缓存继续访问。

## 删除

- 无。

## 优化

- 取消操作停止派发并等待全部在途任务退出，避免取消完成后仍有仓库操作运行。
- fetch、网络自动重试及本地刷新共用一个并发名额，任务启动后保持并发和代理配置快照。
- 历史损坏时保留原文件备份并提示恢复；写入失败保留当前会话结果，不把成功 Git 操作误判为失败。
- 调整历史保留策略时只清理已完成任务，不清理进行中的任务。
- 更新日志按 EXE 对应标签获取并以纯文本显示；说明文件缺失、过大或超时不阻断更新，提供对应版本发布页入口。
