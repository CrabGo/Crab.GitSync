## 新增
- 网络设置页面，支持启用开关、HTTP / SOCKS5 代理、主机和端口配置。
- 默认启用 HTTP 代理 127.0.0.1:33210，配置保存到本机，重启后自动加载。

## 修改
- HTTPS 仓库 fetch 和拉取并合并的远端获取使用已启用的应用代理。
- 应用版本检查与更新下载使用同一代理设置，保存后新请求生效。

## 删除
- 无。

## 优化
- 校验代理类型、主机和端口，无效配置不会覆盖已保存设置。
- 代理仅用于本应用，不修改系统或仓库的持久 Git 设置；关闭时沿用原有网络配置。
- Git 任务使用启动时的配置，避免执行中修改设置影响同一任务。
