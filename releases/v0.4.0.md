## 新增
- 仓库右键菜单：合并、撤销本地修改、拉取、拉取并合并、中止合并。
- 合并分支选择、操作确认及合并冲突状态展示。

## 修改
- 「拉取」仅获取远端更新（fetch），「拉取并合并」获取后合并到当前分支。
- 应用、托盘及 Windows EXE 内嵌图标统一为新的螃蟹 Logo。
- 公开仓库更新使用 GitHub 稳定版本发布地址，无需登录或 Token。

## 删除
- 公开仓库更新流程对 GitHub API 认证的依赖。

## 优化
- 下载更新时强制核对 SHA256，展示下载进度与校验状态。
- 仓库操作前重新核对分支与工作区；撤销修改保留新增及未跟踪文件，合并冲突保留现场。

## 已知问题
- 启动自动检查后再次手动检查更新可能出现 `updater: Init already called`，将在 v0.4.1 修复。
