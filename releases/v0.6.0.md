# Crab.GitSync v0.6.0

## 新增

- 扫描列表支持定时获取远端更新，默认关闭，可设置 1–1440 分钟间隔；显示下次执行时间和最近运行状态。
- 定时任务仅执行 fetch，失败或发现远端新提交时发送汇总通知，无变化成功保持静默。
- 仓库菜单支持选择全部远端、origin 或其他已配置远端；任务结果和失败重试保留所选远端。
- 仓库菜单增加打开目录、在此打开 PowerShell、打开 GitHub 页面和复制脱敏远端地址。
- 撤销本地修改支持逐文件选择、全选和清空，明确确认后只处理所选已跟踪文件。
- 撤销前可主动保存本地备份，从仓库菜单选择备份并确认恢复；独立保留工作区原始字节和暂存区内容。

## 修改

- 定时获取与手动任务共用调度器、仓库锁、并发限制、代理和网络重试；关闭定时开关立即停止后续调度，正在运行的任务可取消。
- 指定远端成功获取不再更新“最后完整获取”时间，避免把部分远端获取误显示为全部最新。
- 撤销界面默认不选文件、不启用备份；改变文件范围或备份选项后需重新确认。未选文件、新增/未跟踪文件及本地提交继续保留。
- 备份写入失败会阻止撤销；仅在原始内容和恢复基线保存成功时提示可恢复。恢复前再次核对仓库、分支、HEAD 和文件状态，拒绝覆盖后续新修改。

## 删除

- 无。

## 优化

- 忙碌时跳过定时任务，休眠恢复不补跑积压；同到期列表优先执行最久未运行项，避免长期饥饿。
- 仓库快捷入口重新核对路径及扫描范围，GitHub 地址限制为有效仓库页面并移除认证信息；复制地址保持脱敏。
- 文件撤销使用字面路径匹配，支持二进制、CRLF、尾部空白、暂存删除和不同的暂存/工作区内容；拒绝越界路径与父目录符号链接。
- 撤销与恢复沿用任务进度、取消收尾、状态刷新及持久化任务历史；备份标识可从日志追溯。
